備份金鑰與還原

記帳資料每週會自動加密備份到 GitHub。這一頁用來產生金鑰和解開備份。所有運算都在你的瀏覽器裡完成，金鑰和資料不會傳到任何地方。

1. 產生金鑰（只要做一次）

會產生一對金鑰：公鑰拿來上鎖（加密），可以公開；私鑰拿來開鎖（解密），只有你能有。

私鑰弄丟了，所有備份都永遠打不開，沒有人能幫你救回。請下載存好，並另外再存一份，例如密碼管理器、隨身碟。

2. 解開備份

到 GitHub 的 backups 分支 點一個 .age 檔，按右上角下載（Download raw file），再選在下面。

JSON 裡是完整的記帳資料（設定、每月紀錄、股價、持股）。要把它還原回記帳台，請找 Claude 協助匯入。

加密方式：age（X25519 + ML-KEM-768 後量子混合金鑰，ChaCha20-Poly1305）。函式庫：typage 0.3.1，放在本站 vendor/ 資料夾，不從外部載入。
